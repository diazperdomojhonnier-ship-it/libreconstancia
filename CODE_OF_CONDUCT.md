# Convivencia y participación

Queremos que LibreConstancia sea un espacio seguro y útil para docentes, desarrolladores y organizaciones pequeñas.

- Tratamos a los demás con respeto, paciencia y buena fe.
- Se aceptan preguntas de principiantes y críticas técnicas fundamentadas.
- No se toleran amenazas, insultos, discriminación, acoso ni divulgación de datos privados.
- No publiques nombres de estudiantes reales, claves privadas o documentos personales en problemas y solicitudes de cambios.
- Para fallos de seguridad con riesgos reales, utiliza el canal privado descrito en [SECURITY.md](SECURITY.md).

La persona responsable del proyecto podrá moderar, solicitar cambios o cerrar intervenciones que incumplan estas reglas. Los desacuerdos técnicos se discutirán con pruebas y explicaciones claras.
