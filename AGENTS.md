# Instrucciones para asistentes de código

- Este es un proyecto educativo libre; no añadir dependencias de servicios comerciales para emisión o verificación.
- Mantener compatibilidad con Python 3.10+ y sin base de datos en la versión 0.1.
- No leer ni copiar claves privadas reales, credenciales o datos de estudiantes.
- No cambiar el formato firmado sin actualizar pruebas, documentación y versión de esquema.
- Antes de una modificación, ejecutar `PYTHONPATH=src python -m unittest discover -s tests -v`.
- Nunca prometer cumplimiento legal ni que una firma prueba la realización del curso.
