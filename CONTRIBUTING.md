# Colaborar

Gracias por ayudar a que organizaciones educativas pequeñas cuenten con herramientas libres.

1. Antes de proponer cambios grandes, describe el problema que quieres resolver y su caso real de uso.
2. Para corregir un fallo, incluye instrucciones reproducibles y pruebas.
3. Ejecuta `PYTHONPATH=src python -m unittest discover -s tests -v` antes de proponer una incorporación.
4. No incluyas claves privadas, contraseñas, nombres de estudiantes reales ni muestras con datos personales.
5. Para cambios en firmas, formatos o verificación, documenta compatibilidad y posibles efectos de seguridad.
6. Mantén las funciones esenciales independientes de servicios comerciales.

Se aceptan especialmente contribuciones de docentes, organizaciones de formación comunitaria y desarrolladores con experiencia en Moodle, WordPress, seguridad y accesibilidad.
